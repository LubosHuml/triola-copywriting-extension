# Icons pro Triola Copywriting AI Chrome Extension

Do teto slozky vloz PNG ikony ve velikostech:

- `icon16.png`  - 16x16 pixelu (favicon a taskbar)
- `icon48.png`  - 48x48 pixelu (rozsirenI stranka)  
- `icon128.png` - 128x128 pixelu (Chrome Web Store)

## Doporuceny design

- Burgundska vinova pozadi (#8C1D31)
- Pismeno "T" zlatou/kremovou barvou (#C9A96E)
- Zaoblene rohy
- Jednoduchy, citelny design

## Nastroje pro vytvoreni ikon

Ikony muzete vytvorit napr.:
- Figma (https://figma.com)
- Adobe Illustrator
- GIMP (zdarma)
- Canva (https://canva.com)
- Favicon.io (https://favicon.io)

## Poznamka

Bez ikon se rozsireni nacte, ale nebude mit vizualni identifikaci.
Chrome Extensions nepodporuji SVG ikony v manifest.json - pouzijte PNG.
